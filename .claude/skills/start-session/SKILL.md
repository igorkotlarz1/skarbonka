name: start-session
description: Start a planned coding session from docs/session-plan.md by its number (e.g. /start-session 3).
disable-model-invocation: true
argument-hint: "[session number, e.g. 3]"
---

Start session S$ARGUMENTS.

1. Read `docs/progress.md` (only the last entry) and the section `## S$ARGUMENTS.` in `docs/session-plan.md`. Do not read other docs unless the task needs them.
2. Restate the task and its "Done when" criterion in 2-3 lines.
3. Propose a short plan: files to create or change, tests to write first, open questions (max 3).
4. Wait for approval before writing code.
