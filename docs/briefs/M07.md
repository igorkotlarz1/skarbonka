## Jak zbudowany jest front (pierwszy raz, więc mapa)
- `src/main.tsx`: start aplikacji, czyli klient zapytań, router i motyw.
- `src/router.tsx`: lista ekranów. Na razie jeden: `/transakcje`.
- `src/api/schema.ts`: typy generowane z API backendu (`npm run api:types`), nic tu nie piszesz ręcznie.
- `src/api/hooks.ts`: pobieranie i zapisy (TanStack Query sam odświeża listę po zmianie).
- `src/pages/transactions.tsx`: cały ekran listy. `src/components/ui/`: gotowe klocki shadcn.
- `src/lib/format.ts`: kwoty formatowane jako tekst, bez zamiany na liczby zmiennoprzecinkowe.
