# Skarbonka frontend

React 19 + TypeScript (strict) + Vite, styled with Tailwind v4 and shadcn/ui, data through TanStack Query, routes through TanStack Router. UI strings are Polish.

```bash
npm install
npm run dev        # http://localhost:5173, proxies API paths to SKARBONKA_API_URL or :8000
npm run lint       # oxlint
npm run build      # type check + production build
npm run api:types  # regenerate openapi.json and src/api/schema.ts from the backend
```

## Layout

- `src/main.tsx` sets up the query client, the router and the theme.
- `src/router.tsx` lists the routes. Filters are URL search params.
- `src/api/` holds the generated `schema.ts`, a typed `fetch` wrapper (`client.ts`) and query hooks (`hooks.ts`).
- `src/pages/` holds one file per screen.
- `src/components/ui/` is generated by `npx shadcn@latest add <name>`; edit freely, it is our code.
- `src/lib/format.ts` formats money as strings. Amounts are never parsed into floats.
